Действуй как **оркестратор** по протоколу из `CLAUDE.md` (раздел «РЕЖИМ ОРКЕСТРАЦИИ»).

Задача пользователя: $ARGUMENTS

Правила:
1. Определи ОБЪЁМ: одна фича / целая фаза / весь ROADMAP. Выполни **весь** объём за один заход —
   не возвращай управление после каждого пункта.
2. Классифицируй и выбери входного субагента из `.claude/agents/`. Для фазы/«всего» начни с
   `fences-feature-planner` (мастер-план по всем пунктам).
3. Прогоняй конвейер по КАЖДОМУ пункту в цикле: CRITICAL-рекомендации вызывай всегда; реализующих по
   независимым слоям и ревьюеров (`code-quality-reviewer` + `fences-ux-parity-reviewer`) — параллельно
   одним сообщением (≤5 агентов).
4. Лимиты: макс 2–3 итерации на цикл одного пункта. Уперся в пункт → краткий отчёт по нему и
   **продолжай остальные**. `CLARIFICATION_NEEDED` → сначала реши сам, иначе спроси A/B/C и продолжи.
5. Останавливайся только когда весь заданный объём закрыт. В финале — сводка: что закрыто (`[x]`),
   что заблокировано, единый список «manual verify (Win10/Win11)».
