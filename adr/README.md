# Architecture Decision Records

Здесь хранятся архитектурные решения проекта DesktopOrganizer.

Формат: `ADR-NNN-краткое-название.md`

Статусы: `Proposed` → `Accepted` → `Deprecated` / `Superseded by ADR-NNN`

Формат шапки: строка `**Статус:**` (русская метка во всех ADR); изменение уже принятого решения записывается как
`Accepted — Amended YYYY-MM-DD (ADR-NNN: суть)` и в шапке, и в разделе `Amendments` в конце изменяемого ADR
(дата, ссылающийся ADR, что изменилось, какие разделы больше не действуют), и в строке этого индекса.
