# Идеи развития

Список возможных фич, не план и не обязательство. Основа — бэклог в `docs/ROADMAP.md` (C1–C11) и известные ограничения из README.

## Панели и рабочий стол
- Правила автосортировки: новые файлы на рабочем столе сами попадают в панель по типу или маске.
- Подсказка «Перетащите значки сюда» в пустой панели.
- Команда «Вернуть все файлы на рабочий стол» в Settings → Backup.
- Отключаемый жест «двойной клик скрывает иконки» и уведомление при первом скрытии.
- Быстрый поиск по содержимому всех панелей.
- Горячие клавиши для переключения страниц и показа панелей поверх окон.

## Надёжность
- Перезапуск приложения после принудительного завершения пакета (`RegisterApplicationRestart`) и восстановление иконок.
- Сохранение `user.config` между обновлениями Store-пакета.
- Мониторинг собственной памяти и хендлов в логе диагностики.

## Store и распространение
- Полная интеграция WinRT `StartupTask` с показом состояния `DisabledByUser`.
- Совместная установка Store-сборки и классического установщика с переносом данных.
- `appExecutionAlias` для ключей командной строки.
- Пакет для arm64.
- Публикация в Store из GitHub Actions; пакет winget.
- Подпись классического установщика.
- Страница лицензий сторонних компонентов в приложении.

## Синхронизация
- Экспорт и импорт раскладки между компьютерами.
- Синхронизация раскладки через облачную папку (OneDrive и т. п.).
