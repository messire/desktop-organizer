# Workspace Grid — единый бэклог долга (для P09)

Консолидация всех находок, оставленных как задокументированный (не молчаливый) долг по итогам этапов
P00–P08 пакета `docs/fix-prompts/` (ветка `bugfix/workspace-grid`). Источник — финальные разделы
верификации каждого этапа (`docs/PLANS/workspace-grid-*.md`, `adr/ADR-028-workspace-grid.md`,
`adr/ADR-029-icon-layout-policy.md`, `docs/DIAGNOSTICS/icon-loading-findings.md`) плюс точечная сверка
кода, выполненная при подготовке этого документа (2026-09-22) там, где находка ещё не была занесена ни в
один из перечисленных файлов. Это входной артефакт для P09 (`docs/fix-prompts/09-acceptance.md`) —
P09 обязан пройтись по каждой строке и либо закрыть, либо явно перенести в release decision.

Статусы: `Open` (не исправлено, требует решения P09), `Manual verify` (код/тест не может доказать,
нужна живая Windows-сессия), `In progress` (чинится параллельно), `Accepted` (сознательный
задокументированный trade-off, не баг), `Closed` (закрыто более поздним этапом — оставлено в таблице
для истории/трассировки).
