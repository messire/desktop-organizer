# Workspace Grid — сводная матрица manual verify (для P09)

Объединяет все пункты ручной проверки на живом Windows-десктопе, накопленные пакетом
`docs/fix-prompts/` (P00–P08, ветка `bugfix/workspace-grid`). Ни один пункт этого документа не был
выполнен в среде разработки текущего цикла (нет живой Windows GUI-сессии, `CLAUDE.md`) — это входной
чек-лист для P09 (`docs/fix-prompts/09-acceptance.md`), не отчёт о выполнении.

Источники (без дублирования — пересекающиеся сценарии сведены в один пункт с несколькими ссылками
«Закрывает»):

1. `docs/PLANS/workspace-grid-03-04-integration.md` §7 (MV-1…MV-29, geometry/drag/resize/mониторы).
2. `adr/ADR-029-icon-layout-policy.md` «Manual verify» (базовый список пп. 1–21 + «Fix-цикл P06» пп. 22–29).
3. `docs/PLANS/workspace-grid-07-visual.md` §9 (usability checklist) и §11 (открытые риски после fix-cycle 2).
4. `docs/DIAGNOSTICS/icon-loading-findings.md` «Manual verify» (пп. 1–8).
5. `docs/PLANS/workspace-grid-migration.md` §8 п.6 (rollback/upgrade real-file).

Префиксы ID сохраняют происхождение (для трассировки к исходному документу), сквозной номер не вводится
намеренно — все источники уже используют собственную стабильную нумерацию, дублирование номеров создало
бы больше риска рассинхрона, чем разные префиксы.

Колонки `Win10`/`Win11`/`DPI` и `Результат` — пустые чекбоксы/поля для P09.
