# Screenshot Baseline Checklist

Фиксирует текущий (до рефакторинга) внешний вид UI, чтобы Фазы 1-6 могли сравнивать "было/стало".
Складывать снимки в `docs/Refactoring/Screenshots/`, см. её `README.md` для соглашения об именах.

## Обязательные состояния (PHASE-0 §4)

- [ ] Idle (панель без взаимодействия)
- [ ] Hover (курсор над заголовком/иконкой)
- [ ] Expanded (обычное развёрнутое состояние)
- [ ] Rolled-up (свёрнута в заголовок)
- [ ] Grid view
- [ ] List view

## Условия съёмки

- Каждое состояние — на светлых **и** тёмных обоях рабочего стола (Ambient Accent, Фаза 5, будет
  сравниваться на обоих).
- Фиксированный размер окна панели (одинаковый во всех снимках одного состояния).
- DPI: 100% и 150% — минимум по одному полному проходу на каждый масштаб.
- Имя файла: `NN-state-dpi.png`, например `01-idle-100.png`, `04-rolledup-150.png`.

## Статус

**Не выполнено в этой среде** — нет живого Windows GUI для рендеринга WPF и снятия скриншотов.
`docs/Refactoring/Screenshots/` — placeholder-папка, ожидает ручного прогона на Win10/Win11.
