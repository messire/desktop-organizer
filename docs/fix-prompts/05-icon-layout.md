# P1 — Предсказуемый fixed-gap icon grid

**Роль:** senior .NET/WPF engineer, Windows shell integration. Следуй `AGENT_CONTRACT.md`. **Вход:** текущий репозиторий, текущий скрин и третий Ambient Accent референс; не переносить размеры с картинки как доказанные константы.

**Зависимость:** результаты этапа 04; не приступай до его DoD. **Вне рамок:** рефакторинг не затронутых модулей, новые продуктовые фичи, переписывание UI на другом фреймворке, полная замена WorkerW/хранилища.

## Задание
Реализуй policy `FixedGap` с одинаковой шириной/высотой слотов и горизонтальными/вертикальными промежутками для одной конфигурации иконок. В `AdaptiveIconGridPanel` перестань распределять остаток по зазорам для **нового режима**, но сохрани старую политику через настройку/миграцию согласно ADR-029. `AdaptiveGridLayout.RowGap` не удалять до переноса тестов; избегать физического изменения исходных размеров изображения. Независимо от panel width позиции 1-й и 2-й иконок одной grid preset совпадают относительно content origin; последний неполный ряд не растягивается; surplus space остаётся справа. Сохрани drag-reorder hit-testing/selection rectangles, overflow/scroll, list mode, доступность label tooltips и виртуализацию при большом числе элементов. Поля item template и layout panel не должны двойным счётом раздувать spacing.

## Выходные артефакты
Policy implementations, XAML bindings/DP, updated ADR-018/029, тесты точных координат, snapshot сравнения 1/3/7 icons и разных panel spans.

## Definition of Done
При одинаковом preset горизонтальный шаг между соседними иконками одинаков в панелях разной ширины; full/partial rows согласованы; ни одна иконка/подпись не пропадает; drag/rename/selection/scroll не регрессируют; legacy layout воспроизводим под явным флагом.
