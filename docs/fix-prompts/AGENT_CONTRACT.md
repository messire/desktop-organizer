# Общие инструкции исполнителю

Работай в существующем репозитории DesktopOrganizer. Перед изменениями посмотри текущую ветку и git status, прочитай `CLAUDE.md`, `adr/README.md`, ADR-011, 015, 017, 018, 021, 022, 025, 026 и соответствующий код. Не выдумывай имена методов/файлов: указанные пути — ориентиры, сверяй их в репозитории. Не перезаписывай пользовательские изменения. Один промпт — один ограниченный PR с тестами и документацией; сохраняй обратную совместимость или явно описывай миграцию.

Работай по TDD для чистой геометрии: сначала characterization / failing tests, затем минимальная реализация. Не смешивай desktop layout grid с icon layout grid. Учитывай WPF DIP vs physical pixels, `PerMonitorV2`, отрицательные координаты мониторов, изменение DPI, WorkerW/re-attach, `WS_EX_NOACTIVATE`, roll-up, virtual desktops, snapshots, collision avoidance, resize cancellation, multi-monitor relocation, hotplug. Все изменения размеров/позиций должны проходить через согласованный layout policy, а не через разрозненные setters. Взаимодействия должны работать и без native sizing (fallback).

В каждом ответе: изменённые файлы, краткое обоснование, решения по совместимости/миграции, команды и результаты тестов (или честно укажи, что не запускались), ручной чек-лист Windows, открытые риски. Не объявляй DoD выполненным без проверок. Не генерируй декоративный «макет», если задание требует реальный WPF код.
